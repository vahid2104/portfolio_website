## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/vahid2104/portfolio_website.git
```

Navigate to the project:

```bash
cd portfolio_website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 📦 Production Build

```bash
npm run build
npm start
```
